## Onboarding

The first time you sign in to an account with no transactions, FundsFlow shows a short welcome:

1. **Welcome to FundsFlow** — a preview of the starter tags created for every new account, plus three choices:
   **Add first transaction**, **Manage tags**, or **Skip**.
2. **Add from Telegram** — an optional step to link the Telegram bot (**Open Telegram to link**) so you can log
   expenses from chat. You can skip it and link later in **Settings → Accounts**.

After that, the action you picked (adding a transaction or managing tags) opens. The welcome is shown once per browser.

## Add your first transaction

Click **Add Transaction** in the header (or the round **+** button in the bottom-right corner):

1. Pick the date: **Today**, **Yesterday**, or **Other date**.
2. Choose **Income** or **Expense** and type the amount. The field accepts `1 500,50`, `1,500.50`, and simple sums like
   `120+35-5`.
3. Pick one or more tags.
4. Optionally add a note and attach images or PDFs.
5. **Save**.

See [Transactions](/docs/web/transactions/) for details.

## Or log it from Telegram

Send the bot a message like:

```text
-350 groceries
```

See [Quick add](/docs/telegram/quick-add/).

## Explore

- Switch the period (**Week / Month / Year**) and use the arrows to move between periods.
- Use **Filter tags** to focus on specific tags or on untagged transactions.
- Browse the tabs: [Analytics, Calendar, Budgets, Tags, Flow, Trend, List](/docs/web/tabs/).
