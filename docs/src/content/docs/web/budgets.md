---
title: Budgets
description: Set spending limits per tag in FundsFlow, pause and resume them, and review history.
---

A budget is a spending limit for one or more tags that repeats **weekly**, **monthly**, or **yearly**.

## Create a budget

On the **Budgets** tab click **Add Budget**:

- **Title** — optional; without it the budget is labelled by its tags' emojis.
- **Tags** — at least one. Spending on these tags counts toward the budget.
- **Amount** — the limit per period.
- **Weekly / Monthly / Yearly**.
- **Start from the beginning of this week/month/year** — align periods to the calendar instead of starting today.

## Track it

Each budget card shows:

- spent / limit for the current period with a progress bar,
- **History** — spent vs limit for previous periods.

## Pause, resume, edit

- **Pause** stops tracking; **Resume** starts a new period from today with the same settings.
- **Edit** changes the budget. FundsFlow keeps the earlier settings in history instead of rewriting the past.
- Delete with hold-to-delete.

## Alerts

With Telegram linked, the bot sends a budget alert at **80%** and **100%** of the limit. See
[Notifications](/docs/telegram/notifications/).
