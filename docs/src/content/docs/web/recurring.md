---
title: Recurring transactions
description: Automate rent, salary, and subscriptions with FundsFlow recurring rules.
---

Recurring rules add transactions automatically — rent, salary, subscriptions.

Open **Recurring** (🔁) from the header, then **Add Recurring**:

- **Amount** (income or expense), **tags**, and an optional **note**.
- **Frequency** — **Daily**, **Weekly**, **Monthly**, or **Yearly**.
- **Starts** — the first date.
- **Ends** — never, after a **number of times** (FundsFlow shows the estimated end date), or on a **date**.

The list shows each rule's frequency, amount, tags, and next run date. You can edit or delete rules
(hold-to-delete).

## When transactions are created

Due rules are processed once a day (06:00 UTC). Created transactions have the source **recurring**. If Telegram is
linked and not muted, the bot sends **🔁 Added automatically** with the list.

Upcoming payments also appear in the [Calendar](/docs/web/tabs/#calendar) and its **Forecast** totals.
